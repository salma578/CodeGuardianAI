\# CodeGuardianAI



\## AI Powered Code Security Scanner



CodeGuardianAI is an AI-inspired source code security analysis tool that detects common programming vulnerabilities, provides security scores, generates automatic fixes, and scans GitHub repositories for security issues.



\---



\# Features



\## 1. Python Code Vulnerability Scanner



Upload or paste Python code and detect:



\- Hardcoded Passwords

\- Weak Passwords

\- Dangerous eval() usage

\- SQL Injection risks





\## 2. Security Score



The system analyzes code quality and provides a security score out of 100.



Example:



Security Score: 20/100



Critical: 1  

High: 2  

Medium: 1
